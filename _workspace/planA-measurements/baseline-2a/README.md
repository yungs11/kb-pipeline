# 2a 기준선 — Phase 2b-1 "동작 무변경" 판정용 (2026-08-13)

## ⚠️ `byte-identical` 은 달성 불가다 — 실측

**같은 2a 코드로 같은 문서를 두 번 돌린 결과**:

| 문서 | 항목 | 1회차 | 2회차 | |
|---|---|--:|--:|---|
| `m2_3lane_7p` | pages | 7 | 7 | ✅ 안정 |
| | tables | 7 | 7 | ✅ |
| | blocks | 126 | 117 | ❌ −9 |
| | chars | 5,837 | 5,820 | ❌ −17 |
| `odl_vl_14p` | pages | 14 | 14 | ✅ 안정 |
| | **tables** | 23 | **24** | ❌ **+1** |
| | blocks | 101 | 88 | ❌ −13 |
| | chars | 13,103 | 12,931 | ❌ −172 |

`vl` 레인이 VL 비결정성을 그대로 받는다. **표 개수까지 흔들린다.**
→ 내용 비교로는 "회귀" 와 "VL 흔들림" 을 구분할 수 없다.

## 그래서 판정은 **구조만** 한다 (사용자 결정 2026-08-13)

`structure.json` 이 정본이다:
- `pages` — 페이지 수
- `lanes` / `lane_dist` — 페이지별 레인 배정
- `doc_lane` · `narrate_pages` · `diagram_pages`
- `page_verdicts` 건수(또는 None)

2b-1 은 **기록만 추가**하므로 라우팅과 분기 선택이 같으면 동작이 같다.
여기에 2b-1 이 신설하는 `source` 분포가 더해진다.

**못 잡는 것**: `vl_elements_to_blocks` 같은 변환 단계의 미세 회귀.
그건 단위 테스트가 담당한다(§4 앵커).

## 파일

- `structure.json` — **판정 기준선**
- `baseline.json` — 1회 실행의 전체 산출물(블록별 sha 포함). **참고용**이지 판정용이 아니다.
