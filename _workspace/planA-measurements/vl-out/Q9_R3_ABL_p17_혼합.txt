## SECTION 02 | 온톨로지 PoC의 올바른 방향과 목표 설정

# 기초서류 자동작성 PoC의 전략적 의미

기초서류는 상품 지식의 기준 원장이며, 온톨로지는 후속 업무가 반복 재사용하는 Product Knowledge Core입니다.

### 도메인 관점

생명보험 상품의 모든 후속 업무는 기초서류에 정의된 상품 지식에서 출발한다.
따라서 기초서류 자동작성은 가장 중심 지식부터 AI화하는 전략적 출발점이다.

- **기초 서류**
  - ↑ **인수 심사**
  - ← **가입 설계**
  - → **보험료 산출**
  - ↓ **보험금 지급심사**
    - → **민원·분쟁 대응**
  - ↑ **판매 설명 / 상품 안내**

- **계약 관리 / 보전**

### 기준성
상품의 보장, 조건, 제한, 산출방식이 공식화되는 기준 문서

### 연결성
상품개발, 설계, 심사, 지급, 민원 업무의 출발점

### 검증성
조항 누락, 조건 불일치, 산출 기준 오류를 검증할 수 있는 대상

### 온톨로지 관점

기초서류 작성을 위해 필요한 온톨로지 모델은 특정 문서용 템플릿이 아니라, 생명보험 상품업무 전반에서 반복 재사용되는 공통 의미 구조다.

- **기초서류 자동작성 PoC**
  - ↓ **모델링**
    - **Product Knowledge Core Ontology**
      - ↓ **재사용 / 확장**
        - 가입설계
        - 인수심사
        - 판매설명
        - 지급심사
        - 계약관리
        - 민원대응

### 기초서류 작성 시 모델링하는 지식 | 후속 업무 재사용 예

| 구분 | 내용 |
|---|---|
| 상품, 주계약, 특약, 담보 구조 | 상품설계, 상품비교, 추천, 포트폴리오 분석 |
| 가입나이, 보험기간, 납입기간, 가입한도 | 가입설계 검증, 청약 오류 탐지, 인수심사 |
| 지급사유, 보험금 종류, 지급조건 | 보험금 지급심사, 청구 안내, 약관 질의응답 |
| 면책사유, 감액기간, 부담보, 제한조건 | 인수심사, 지급심사, 민원·분쟁 대응 |
| 보험료, 해약환급금, 산출 기준 | 보험료 산출 검증, 환급금 안내, 계약관리 |
| 약관 조항과 사업방법서 항목 간 관계 | 약관 정합성 검증, 개정 영향도 분석 |
| 상품 변경 시 영향받는 조항·규칙 | 상품개정, 리스크 검토, 컴플라이언스 점검 |
