SECTION 04 | 온톨로지 확장 전략
AI 에이전트 기반 온톨로지 자동 구축
Agent/Document/Knowledge Studio 기반

스미카 반자동 설계:
원천 데이터의 의미 구조를 분석하여 OWL/RDFS 기반의 도메인 최적화 온톨로지 스키마 생성
- 온톨로지 핵심 정보 → 정보 분석 에이전트 LUXIA3.5-Deep → 분석결과, 검색 쿼리 → 정보 검색 에이전트 A.RAG / LUXIA-Embedding → 내/외부 문서 → 핵심정보+검색결과 → 스키마 생성 에이전트 LUXIA3.5-LLM → 스키마 정보
<스키마 생성 자동화>

온톨로지 인스턴스 자동 추출:
개체명 인식(NER) 및 관계 추출(RE) 기술로 대규모 텍스트·문서에서 의미 있는 트리플(Subject-Predicate-Object)을 정확하게 추출
- 비정형 데이터 → 문서 파싱 에이전트 Document Studio → 구조화된 파싱 결과 → 스키마 검색 에이전트 LUXIA3.5-Deep → 파싱 결과, 스키마 정보 → 트리플 추출 에이전트 LUXIA3.5-LLM → 온톨로지 정보
<온톨로지 정보 추출 자동화>

자동화 정합성 검증:
SHACL 규칙 및 추론 엔진 기반으로 스키마 충돌, 트리플 오류, 누락된 관계를 AI가 실시간 탐지하여 즉시 보정
- 온톨로지 정보 → 정보 통합 에이전트 중복 제거 / 지식 충돌 (False: 충돌 안내, True: 다음 단계) → 정보 검증 에이전트 LUXIA3.5-Deep (False: 충돌 안내, True: 다음 단계) → 적재 에이전트 Knowledge Studio
